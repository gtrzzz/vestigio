# VESTIGIO — Entrega 3B · Expediente 214

Entrega acumulativa: incluye todo el motor de matrices de 3A y añade el expediente cinematográfico.

## Incluye

- 20 imágenes originales estilo expediente;
- selección de archivos válidos;
- metadatos/checksum;
- visor con rotación, negativo y contraste;
- notas persistentes;
- marcadores importantes;
- fase de palabras clave;
- concepto final `SOLO YO`;
- preparado para integrarse con la revelación del perfume.

## Flujo

1. Completa las 10 matrices.
2. Abre el expediente 214.
3. Selecciona únicamente los archivos con checksum válido.
4. Introduce las palabras asociadas.
5. El sistema recupera `SOLO YO`.
